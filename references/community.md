# Community

Use this reference for Reddit-like forums, community chatter, social platforms, discussion threads, and maintenance-signal gathering.

## Principle

Community sources are useful for:
- finding real pain points
- spotting edge cases and maintenance issues
- seeing user sentiment and adoption patterns

But they are weaker than source code and docs for factual implementation details.

## Use community signals for

- "What do users complain about?"
- "What breaks in real use?"
- "Is this maintained or abandoned?"
- "What hidden setup costs keep appearing?"

## Do not over-trust community chatter for

- exact technical behavior
- current official support status
- security guarantees

## Best practice

Use community evidence as a second layer:
1. inspect source/docs first
2. use issues/discussions/posts to pressure-test claims
3. report both upside and fragility
