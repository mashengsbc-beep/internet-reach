# Video

Use this reference when the task involves YouTube, Bilibili, talks, demos, or video-style learning resources.

## Default strategy

1. Prefer official docs / repo / transcript over watching a whole video when the goal is implementation.
2. Use videos when the value is demonstration, walkthrough, UI flow, or commentary.
3. If a project links a video but also has README/docs/code, read the text/code first.

## Evaluation lens

For video-backed projects or tutorials, ask:
- Is the video explaining a real implementation or just a concept demo?
- Is there a repo, script, or transcript to verify details?
- Does the video add operational knowledge unavailable in text?

## Output

When summarizing video-related material, separate:
- what is shown
- what is claimed
- what is reproducible from available code/docs
