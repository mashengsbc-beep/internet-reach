# Adoption Template

Use this reference when the user wants a concrete "what should we do with this" answer.

## Minimal adoption plan

Answer in this shape when appropriate:

### 1. Directly adopt
List the pieces that already fit this workspace well.

### 2. Adapt / simplify
List ideas worth keeping, but implemented with native OpenClaw tools or lighter local patterns.

### 3. Do not import blindly
List external stacks, integrations, or assumptions that should not be copied as-is.

### 4. Recommended next step
Choose one:
- try it on one real task
- convert the method into a local skill
- monitor only
- skip installation entirely

## Good examples of "adapt / simplify"

- Keep the routing logic, not the giant installer
- Keep the evaluation method, not the full support matrix
- Keep GitHub-first research, not every extra social connector
- Keep health-check thinking, not a fragile dependency chain
